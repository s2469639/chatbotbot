# 보안 및 환경 변수 규칙 (.env 보호)

1. **.env 파일 접근 엄격 금지**
   - `.env` 파일은 절대 열거나 읽지 마십시오 (`read_file`, 스크립트 실행 등을 통한 확인 일체 금지).
   - `.env` 파일의 내용을 수정, 편집하거나 덮어쓰지 마십시오.
   - 새 프로젝트나 작업 시에도 임의로 `.env` 파일을 직접 생성하지 마십시오.

2. **환경 변수 참조 및 확인 절차**
   - 파이썬 코드에서는 항상 `os.getenv("VARIABLE_NAME")` 형태로 안전하게 환경 변수를 조회하도록 작성하십시오.
   - 어떤 환경 변수가 필요한지 안내해야 할 경우, 실제 키 값이 포함되지 않은 예시 템플릿 파일인 `.env.example`을 작성하여 사용자에게 안내하십시오.
   - 변수명이나 설정이 불명확할 경우 임의로 추측하지 말고 사용자에게 직접 질문하여 확인하십시오.
